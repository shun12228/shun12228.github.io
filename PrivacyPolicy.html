プライバシーポリシー

最終更新日: 2026年10月29日

本プライバシーポリシー（以下「本ポリシー」）は、当方（hayabusa2.dev、以下「開発者」）が提供するすべてのアプリケーション（以下総称して「本アプリ」）において取得・利用する情報、利用者の権利、免責等について定めるものです。本アプリをインストール、閲覧、または利用することで、利用者は本ポリシーのすべての条項に同意したものとみなされます。同意いただけない場合は、本アプリの利用を直ちに中止してください。

1. 収集する情報

  1. 利用者が端末上に保存するデータ
    端末のカメラ・フォトライブラリ・ストレージ等へのアクセスは、アプリ機能の提供に必要な範囲でのみ行い、開発者のサーバーへ自動アップロードすることはありません。
  2. 広告配信関連情報
    第三者広告サービス（Google AdMob / Google Mobile Ads SDK 等）が端末識別子（広告ID 等）、推定位置情報（概略）、利用状況データを自動的に収集する場合があります。詳細は各事業者のポリシーをご参照ください。
  3. 課金・購入情報
    アプリ内課金の処理は Apple / Google / RevenueCat 等のプラットフォーム事業者が行い、開発者がクレジットカード番号等の決済情報を直接取得することはありません。購入履歴・サブスクリプション状態等の管理情報を間接的に受領する場合があります。
  4. クラッシュ / 利用状況
    安定性向上と機能改善のため、クラッシュログや匿名化された統計情報（画面の表示や機能の利用状況など）を、Firebase（Google Analytics for Firebase / Firebase Crashlytics）等を通じて取得する場合があります（個人を直接特定しない形で扱います）。アプリ内に送信を停止する設定がある場合は、いつでも停止できます。
  5. お問い合わせ情報
    任意で送信されたメールアドレス・問い合わせ本文は回答および履歴管理の範囲で利用します。

2. 情報の利用目的

  • アプリ機能の提供・改善・不具合調査

  • 広告表示の最適化（同意が必要な地域ではユーザー同意取得後）
  • 課金・購入状態の管理

17. アプリ別の補足

以下のアプリでは、上記に加えて次のとおり取り扱います。

ノコリ - 引き算おこづかい帳

  • 記録の内容: 予算・支出・固定費・メモなど、利用者がアプリに記録した内容は端末内（および iOS のバックアップ）にのみ保存され、開発者に送信されることはありません。
  • 利用状況とエラー: アプリの改善のため、どの画面や機能を使ったか（例: グラフを開いた、CSV を書き出した）と、クラッシュ等のエラー情報を、Google Analytics for Firebase と Firebase Crashlytics で匿名で収集します。記録の内容（金額・メモ等）は含みません。広告ID（IDFA）は使用せず、広告目的には利用しません。
  • 送信の停止: アプリの「設定 > プライバシー > 利用状況とエラーの送信」をオフにすると、以後は送信しません。
  • CSV の書き出し: 書き出したファイルは端末内で作成され、利用者が選んだ保存先・共有先にのみ渡されます。

けんたびアルバム - 47都道府県制覇の旅記録

  • 写真と位置情報: 旅の写真を都道府県・日付ごとのアルバムに自動で振り分けるため、利用者が許可した場合に限り、フォトライブラリの写真と、写真に記録された撮影場所（緯度・経度）・撮影日時を読み取ります。都道府県の判定はアプリに内蔵した地図データを使って端末内で行い、写真・撮影場所・撮影日時を開発者や第三者に送信することはありません。
  • アルバムに追加した写真: 縮小したコピーを端末内（および iOS のバックアップ）にのみ保存します。アルバムから削除しても、フォトライブラリの元の写真は変更・削除しません。
  • アクセスの変更: 写真へのアクセスは、端末の「設定 > けんたびアルバム > 写真」からいつでも変更・取り消しできます。
  • 地図データの出典: 都道府県の判定には「国土数値情報（行政区域データ）」（国土交通省）を加工して使用しています。
